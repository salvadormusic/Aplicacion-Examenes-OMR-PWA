# Aplicación de Exámenes OMR PWA

Una aplicación web para corregir exámenes tipo test de hasta 20 preguntas, diseñada para automatizar la evaluación de respuestas en formato de hoja de examen.

This is a web application for grading multiple-choice tests with up to 20 questions, designed to automate the evaluation of answers in exam-sheet format.

## Español

### ¿Qué es?
Esta aplicación permite digitalizar y corregir exámenes tipo test de forma rápida y sencilla. Está pensada para facilitar la evaluación automática de preguntas de opción múltiple, reduciendo el tiempo necesario para revisar cada prueba.

### Características
- Corrección de exámenes tipo test
- Soporte para hasta 20 preguntas
- Interfaz web accesible desde navegador
- Diseño orientado a PWA (Progressive Web App)
- Mejoras continuas para optimizar la experiencia de uso

### Estado del proyecto
El proyecto está en constante evolución. Se siguen incorporando mejoras para aumentar su precisión, usabilidad y rendimiento.

## English

### What is it?
This application allows you to digitize and grade multiple-choice exams quickly and easily. It is designed to simplify the automated evaluation of option-based questions and reduce the time needed to review each test.

### Features
- Grading for multiple-choice exams
- Support for up to 20 questions
- Web interface accessible from a browser
- PWA-oriented design (Progressive Web App)
- Ongoing improvements to enhance usability and performance

### Project status
The project is in continuous development. New improvements are being added to increase its accuracy, usability, and performance.
