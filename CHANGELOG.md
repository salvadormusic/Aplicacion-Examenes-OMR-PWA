# Historial de cambios / Changelog

Este archivo registra los cambios importantes de cada versión. Las entradas de abajo describen el estado actual del proyecto; todavía no implican que exista una etiqueta o una Release publicada en GitHub.

## Sin versión etiquetada

- Aplicación web progresiva (PWA) para crear y guardar formularios de examen.
- Soporte para exámenes de hasta 20 preguntas.
- Impresión de hojas de respuestas en formato A4.
- Corrección de respuestas a partir de una foto mediante OMR y OpenCV.

## Formato para futuras versiones

Al publicar una versión, añade una sección nueva al principio con su número y fecha, por ejemplo:

```markdown
## [1.0.0] - AAAA-MM-DD

### Añadido
- Describe aquí las funciones nuevas.

### Corregido
- Describe aquí los errores corregidos.
```

Para publicar una versión en GitHub, crea una etiqueta (por ejemplo, `v1.0.0`) y una Release asociada desde la página **Releases** del repositorio.
