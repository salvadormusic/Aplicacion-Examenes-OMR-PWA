# Historial de cambios / Changelog

Este archivo registra los cambios importantes de cada versión. Las entradas documentan las versiones del proyecto; una entrada en este archivo no significa por sí sola que exista una etiqueta (tag) o una Release publicada en GitHub.

## [1.2.0] - 2026-11-18

### Añadido
- Soporte para crear y guardar varios formularios de respuestas.
- Enlace de donación a Médicos Sin Fronteras en el pie de página.
- Enlace al perfil del creador desde el pie de página.

## [1.0.0] - fecha por confirmar

### Añadido
- Aplicación web progresiva (PWA) para crear y guardar formularios de examen.
- Soporte para exámenes de hasta 20 preguntas.
- Impresión de hojas de respuestas en formato A4.
- Corrección de respuestas a partir de una foto mediante OMR y OpenCV.
